How Whitford Global College uses Ethereum

Student records, grades and personal data stay in the college's own systems. Only a fingerprint of each award and the points are on-chain.

Student enrols, wallet linked→Earns Merit Points→Redeems campus perks→Award approved, credential NFT issued→Employer verifies in seconds
  1. ERC-721 (WhitfordCredential): one soulbound credential per award. It stores a salted hash of the certificate file, the programme code, NFQ level and award date. No name or grades.
  2. ERC-20 (WhitfordPoints): Whitford Merit Points, 0 decimals, non-transferable, only for enrolled students, with a cap of 500 per award.
  3. Why a salted hash? The hash proves a file is genuine without revealing it. The salt stops anyone guessing the hash, which supports GDPR.
  4. The QQI certificate remains the official award. The credential is a verifiable companion to it.
